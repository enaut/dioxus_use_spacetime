## [0.1.0] - 2024-11-14

### Added

- Initial release of dioxus_use_spacetime
- Core connection management via `SpacetimeConnection`
- Context-based API with `SpacetimeContext`
- Reactive table subscriptions via `use_table` hook
- Single row subscription via `use_table_row` hook
- Connection initialization via `use_spacetime_init` hook
- Table filtering support with `TableFilter`
- Comprehensive error handling
- Example application demonstrating basic usage
- Full documentation with inline examples
- MIT and Apache-2.0 dual license

### Features

- 🔄 Reactive table subscriptions with automatic UI updates
- 🎣 Familiar Dioxus hook-based API
- 🔌 Context-based connection management
- 🎯 Type-safe Rust implementation
- 🔍 Filtering support for table subscriptions
